# Proyecto Desarrollo de Multimedia y Videojuegos

## Objetivo del proyecto

Desarrollar un videojuego interactivo en donde se concientice sobre una situación real, en este caso relacionaod con los desastres naturales. 

## Misión Rescate Inundación

Es un videojuego 2D desarrollado en Godot, cuyo escenario principal está relacionado con una situación de inundación y actividades de rescate. El proyecto integra elementos gráficos, personajes, objetos, vehículos y recursos de audio para construir una experiencia interactiva.

## ¿Cómo abrirlo?

- Abrir Godot versión 4.2 o superior y pulsa "Importar". Selecciona project.godot.
- Espera a que importe sprites y audios, y pulsa F5.

## ¿Cómo se juega?

- Flechas o W, A, S, D: mover.
- E o Espacio: ayudar e interactuar.
- Q: usar botiquin (solo en el nivel 3)
- Enter: Inicio de nivel, siguiente nivel, reintentar
- 1 - 2 - 3 en la pantalla de inicio de nivel: Saltar a ese nivel
- M: silenciar ó activar el sonido
